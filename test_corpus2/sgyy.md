# 三国演义

刘备，字玄德，人称刘皇叔，是汉景帝之子中山靖王刘胜的后代。他于公元184年桃园结义，与关羽、张飞结为兄弟。

关羽，字云长，使青龙偃月刀，被后世尊为武圣。张飞，字翼德，性烈如火，曾在长坂坡一声吼退曹军百万。

公元207年，刘备三顾茅庐，请出诸葛亮。诸葛亮，字孔明，号卧龙，提出三分天下的隆中对。

赤壁之战发生于公元208年冬。孙权命周瑜为大都督，联合刘备军，火烧曹操战船。曹操，字孟德，号称百万大军南下，却大败而归。

周瑜，字公瑾，与黄盖演出苦肉计。黄盖假降曹操，乘东风火烧连环船。此战后，天下三分之势已成。

曹操退守北方，刘备借荆州入川。公元214年，刘备取益州。公元221年，刘备在成都称帝，建立蜀汉。

诸葛亮六出祁山北伐中原，均未成功。公元234年，诸葛亮病逝于五丈原，蜀汉逐渐衰落。

司马懿，字仲达，隐忍多年，最终其孙司马炎建立晋朝，统一天下。
