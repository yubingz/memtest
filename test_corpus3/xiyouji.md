# 西游记

孙悟空，又名齐天大圣、美猴王、行者，原是花果山一块仙石孕育的石猴。他拜菩提祖师为师，学得七十二变和筋斗云。

大闹天宫后，如来佛祖将孙悟空压在五行山下五百年。唐僧，俗名陈玄奘，奉观音菩萨之命前往西天取经，路过五行山救出孙悟空，收为大徒弟。

猪八戒，又名天蓬元帅、呆子，因调戏嫦娥被贬下凡，错投猪胎。他在高老庄被孙悟空收服，成为唐僧的二徒弟。

沙悟净，又名卷帘大将、沙和尚，因在蟠桃会上打碎琉璃盏被贬流沙河。经观音菩萨点化，在流沙河等候取经人，成为唐僧的三徒弟。

白龙马，本是西海龙王三太子敖烈，因纵火烧了殿上明珠被判死罪。观音菩萨救下他，让他化为白马驮唐僧取经。

火焰山横亘在西行路上，终年烈火不息。铁扇公主，又名罗刹女，持有芭蕉扇可灭火。她是牛魔王的妻子，红孩儿的母亲。孙悟空三次借芭蕉扇，前两次被骗，第三次变成牛魔王骗得真扇。

红孩儿，又名圣婴大王，是牛魔王与铁扇公主之子，会三昧真火。他曾在火云洞捉走唐僧，最终被观音菩萨收为善财童子。

白骨精三次变化欺骗唐僧，分别变成村姑、老妇和老翁。孙悟空火眼金睛识破，三打白骨精，但唐僧不知真相，念紧箍咒赶走孙悟空。

女儿国位于西梁女界，全境无男子。国王欲招唐僧为夫，唐僧西去心坚，婉言拒绝。

花果山，位于东胜神洲，是孙悟空的道场。水帘洞是花果山顶的洞府，洞口有瀑布遮蔽。流沙河，河宽八百里，鹅毛浮不起，是沙悟净被贬后的居所。
