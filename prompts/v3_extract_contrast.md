# v3 对比推理记忆提取 Prompt

## 目标
从语料中提取**相似人物做了不同/相反事情的对比对**，用于生成对比推理查询。

## 核心原则
1. **对比对**：两个相似人物（如同一类人）在相似情境下做了不同/相反的事
2. **文本依据**：对比关系必须在原文中有体现
3. **忠实原文**：每条 content 保留原文片段

## 输入
语料文本片段

## 输出要求
JSON 对象数组，每组对比对：

```json
{
  "contrast_id": "CT001",
  "entity_a": {
    "name": "人物A名称",
    "content": "原文片段A（30-150字）",
    "person": ["人物A"],
    "action": "做了一件什么事",
    "location": "地点或 null",
    "time_absolute": "时间或 null",
    "event_type": "事件类型"
  },
  "entity_b": {
    "name": "人物B名称",
    "content": "原文片段B（30-150字）",
    "person": ["人物B"],
    "action": "做了另一件什么事（与entity_a不同或相反）",
    "location": "地点或 null",
    "time_absolute": "时间或 null",
    "event_type": "事件类型"
  },
  "contrast_dimension": "对比维度（如：选择、态度、结果）",
  "source": "来源或 null"
}
```

## 提取规则

### 对比类型
- **结果对比**：同一选择导致不同结果
- **态度对比**：相似情境下态度相反（如一忠一奸）
- **行为对比**：相似身份的人做不同选择
- **境遇对比**：同一事件对不同人的影响

### 示例

### 输入语料
> 曹操与刘备青梅煮酒论英雄。曹操认为乱世之中，唯有英雄才能成就大业。而刘备却说：大丈夫处世，应当匡扶汉室，绝不与奸贼为伍。两人对英雄的定义截然不同。

### 输出
```json
[
  {
    "contrast_id": "CT001",
    "entity_a": {
      "name": "曹操",
      "content": "曹操认为乱世之中，唯有英雄才能成就大业。",
      "person": ["曹操"],
      "action": "认为英雄在于成就大业",
      "location": null,
      "time_absolute": null,
      "event_type": "论英雄"
    },
    "entity_b": {
      "name": "刘备",
      "content": "刘备却说：大丈夫处世，应当匡扶汉室，绝不与奸贼为伍。",
      "person": ["刘备"],
      "action": "认为英雄在于匡扶汉室",
      "location": null,
      "time_absolute": null,
      "event_type": "论英雄"
    },
    "contrast_dimension": "对英雄的定义",
    "source": null
  }
]
```

## 注意事项
- **必须有文本依据**：对比关系要在原文中有体现，不靠推理得出
- **相似人物**：对比对的人物应有某种相似性（同一阵营、同一身份、同一时代等）
- **action 字段**：标注每个实体"做了什么"，便于生成对比查询
