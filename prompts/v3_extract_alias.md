# v3 别名等价记忆提取 Prompt

## 目标
从语料中提取**有明确等价证据的称呼**，用于生成别名查询。

## 核心原则
1. **只认语料证据**：必须从原文找到等价陈述（"X 就是 Y""X，即 Y""X，别名 Y"）
2. **不用外部知识**：语料没说的等价关系，不建立
3. **忠实原文**：content 保留原文证据片段

## 输入
语料文本片段

## 输出要求
JSON 数组，每条记录：

```json
{
  "entity": "标准名称",
  "aliases": ["称呼1", "称呼2", "称呼3"],
  "evidence": "原文中的等价证据句子",
  "content": "原文完整段落（保留上下文）",
  "person": ["人物名"],
  "location": "地点或 null",
  "event_type": "事件类型或 null",
  "source": "来源或 null"
}
```

## 提取规则

### 等价证据模式（必须有文本明确证据）
- "X 就是 Y"
- "X，即 Y"
- "X，别名 Y"
- "X，又称 Y"
- "X，也就是 Y"
- "X，人称 Y"
- "X，江湖人称 Y"
- "X，绰号 Y"
- "X（也就是 Y）"
- "X（金陵）" — 地名的古今对照

### 注意事项
- **无证据不提取**：语料没明确说等价，就不提
- **区分真假等价**：同名的不同人/地要分开（如"长安"在汉代和唐代指不同地）
- **别名不限于人名**：可以是地名、物品名、事件名等
- **证据必须包含原词**：evidence 字段要包含两个等价称呼的原词

### 示例

### 输入语料
> 林黛玉，大名颦儿，林妹妹是贾府上下对她的昵称。她姿容绝世，才情横溢，与贾宝玉青梅竹马。

### 输出
```json
[
  {
    "entity": "林黛玉",
    "aliases": ["颦儿", "林妹妹"],
    "evidence": "林黛玉，大名颦儿，林妹妹是贾府上下对她的昵称",
    "content": "林黛玉，大名颦儿，林妹妹是贾府上下对她的昵称。她姿容绝世，才情横溢，与贾宝玉青梅竹马。",
    "person": ["林黛玉"],
    "location": "贾府",
    "event_type": "描述",
    "source": "红楼梦"
  }
]
```

### 反例（不应提取）

> 贾宝玉和林黛玉经常一起读书。

解释：虽然"宝黛"常被并称，但文本中未明确说"林黛玉就是林妹妹"，不提取别名关系。
