# v3 事实检索记忆提取 Prompt

## 目标
从语料中提取**包含明确地点、人物、事件**的事实，用于生成事实检索查询。

## 核心原则
1. **三要素明确**：必须有明确人物（或地点），可选地点和事件
2. **忠实原文**：content 保留原文，不改写
3. **不过度提取**：不需要时序/因果/别名关系的事实，单独提取

## 输入
语料文本片段

## 输出要求
JSON 数组，每条记录：

```json
{
  "content": "原文片段（30-150字，忠实原文）",
  "person": ["人物列表"],
  "time_absolute": "绝对时间或 null",
  "time_relative": "相对时间或 null",
  "time_ref_id": null,
  "time_offset_days": null,
  "location": "地点或 null",
  "event_type": "事件类型或 null",
  "source": "来源或 null",
  "tags": ["标签1"]
}
```

## 提取规则

### 事实类型
- 人物 + 事件（最简单）
- 人物 + 地点 + 事件
- 人物 + 时间 + 地点 + 事件（最完整）

### 事件类型标签（参考）
- 出生/死亡
- 就职/离职
- 婚嫁/离别
- 会议/谈判
- 发明/发现
- 冲突/和解
- 旅行/归来
- 交易/赠送

### 示例

### 输入语料
> 秦始皇二十六年，丞相李斯奉命统一度量衡在全国推行。这次改革奠定了后世两千年的标准。

### 输出
```json
[
  {
    "content": "秦始皇二十六年，丞相李斯奉命统一度量衡在全国推行。",
    "person": ["李斯", "秦始皇"],
    "time_absolute": "秦始皇二十六年",
    "time_relative": null,
    "time_ref_id": null,
    "time_offset_days": null,
    "location": null,
    "event_type": "改革",
    "source": null,
    "tags": ["历史事实"]
  }
]
```

## 注意事项
- **content 粒度**：30-150字，截断超长的，合并过短的
- **时间模糊可接受**：如果时间模糊（如"某年"），留空即可
- **不过度拆分**：一个段落讲一件事就提取一条，不要把一段话拆成多个事实
